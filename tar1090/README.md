# Local Aircraft (tar1090)

An experimental Home Assistant OS App that hosts the aircraft map beside your dashboard and fetches one compressed snapshot from a remote receiver. Multiple displays share the collector. Designed for a constrained wireless receiver link.

Five-second updates are the default. History is accumulated locally in memory and resets when the app restarts. No decoder, SDR, MQTT broker, advertising, or commercial account is required.

See DOCS.md for installation, dashboard embedding, settings, limitations, and troubleshooting. Check the release and validation notes before installation; experimental status is intentional.
